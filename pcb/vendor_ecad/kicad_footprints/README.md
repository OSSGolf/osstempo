# KiCad footprints used by the osstempo LED carrier

## Stock footprints (official KiCad)

Byte-identical copies from the KiCad 10.0.6 install
(`/Applications/KiCad/KiCad.app/Contents/SharedSupport/footprints/`), which ships the
official library <https://gitlab.com/kicad/libraries/kicad-footprints> under CC-BY-SA-4.0
with the KiCad libraries exception (same licence text as `../kicad_symbols/LICENSE.md`).

| Footprint | Used by |
|---|---|
| `Capacitor_SMD.pretty/C_0805_2012Metric` | C1-C6 |
| `Resistor_SMD.pretty/R_0805_2012Metric` | R1 |
| `Connector_PinSocket_2.54mm.pretty/PinSocket_1x15_P2.54mm_Vertical` | source for the derived H1/H2 footprint below |
| `Connector_JST.pretty/JST_XH_S3B-XH-A_1x03_P2.50mm_Horizontal` | J1 |

Each component pack under `../../component_packs/` records the SHA-256 of the footprint
it references; the toolkit checks it at build time. To add one, copy it from the install
and record it as `source_type: official-kicad`.

## Our own artwork (`OSSTempo.pretty/`)

Pad-less silkscreen-only footprints generated by `../../tools/make_logo_footprint.py`
(TrueType text and simple shapes baked to outline polygons, so the fab package has no font
dependency):

- `PinSocket_1x15_P2.54mm_Vertical_Pad2.0` — H1/H2 (v1.2): the official socket footprint with
  2.0 mm pads instead of 1.7 mm, derived by `../../tools/make_socket_footprint.py`; recorded in
  `component_packs/samtec-ssw-115-01-t-s.yaml` as `datasheet_land_pattern` with its SHA-256
- `Silk_Back_v1_2` — the whole back side of the current board (URL, golf ball with
  script logo, solder arrows and pin labels, Austin line), generated from
  `../../examples/osstempo_led_carrier/artwork/silk_back_v1_2.json` with `--spec`
- `Logo_OSSTempo_v1_1`, `Logo_OSSTempo_v1_0`, `Mark_ossgolf_com` — the earlier back-side
  artwork, kept so the v1.0 and v1.1 releases can be regenerated
- `Mark_USB_End` — orientation mark at the USB edge, front side

Declared as `source_type: generated` in the manifest. Regenerate rather than hand-edit.
